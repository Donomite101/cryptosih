# CryptoSentinel frontend

React 19 + Vite 5 single-page app. See the main [README](../README.md) for setup and [docs/05-report-and-ui.md](../docs/05-report-and-ui.md) for how the UI works.

```bash
npm install
npm run dev      # http://localhost:5174  (proxies /api to http://localhost:8001)
npm run build    # production build in dist/
```

The backend must be running on port 8001 (see the main README).
